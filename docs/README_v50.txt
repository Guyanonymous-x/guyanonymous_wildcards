Guyanonymous' Wildcards v50 - furniture and appliances in parts
================================================================
A bed is a headboard (or none), a footboard (or none), a frame, feet, a mattress, bedding and a size. Each part is its own file and can be used alone.

Whole item   furn_<item>_built (also _built_short, _built_phrase, _prompt)   e.g. __furn_bed_built__  __furn_toilet_built__  __furn_refrigerator_built__
Single part  furn_<item>_<part> and furn_<item>_<part>_prompt                e.g. __furn_bed_headboard_prompt__  __furn_bed_footboard_prompt__
Bed boards   furn_bed_boards / furn_bed_boards_prompt                        matching headboard + footboard (or none, or headboard only)
Shared       part_wood, part_fabric, part_metal, comp_colour
