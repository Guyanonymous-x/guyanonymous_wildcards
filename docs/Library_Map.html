What each group does: the shoe, step by step

A shoe description is built from many small files. Each group below fills one phrase of the finished sentence. The same layout is reused by the other accessory families, so reading the shoe once explains most of acc_*.

Example of Route B output: A pair of basic stacked-heel ankle boots designed by an origami-inspired engineer, made of mesh and synthetic overlays in burnt orange, injection-molded in one piece. They have a chiseled toe and feature embossed patterning. They rest on a block heel above a molded plastic outsole. Stretch elastic panels let it slip on. Practical details include a kick guard. The interior is unlined. Bold phrases come from word, type, designer, material, colour, construction, toe, detail, sole, closure, extras and lining.

The shared accessory layout

Gloves, hats, belts, bags, jewellery and the rest use the same group names as shoes, with a few differences. Shoes have extra groups for heel, sole and footbed. Other families put item kind, material and a practical note into one cluster file.
