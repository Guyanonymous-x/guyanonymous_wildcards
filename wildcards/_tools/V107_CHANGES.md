# v107 changes

Released. Built by `v107_build.py` (overlay of `v107_stage.py` on v106), packaged with `finish.py 107`.

## Library
- `f_body_nipples`: 35 new lines pairing five areola sizes (thumbnail-small, about 2 cm, about 3.5 cm, about 5 cm, about 7 cm) with seven nipple forms (tiny flat, small neat, medium, long, thick wide, inverted, puffy dome) and a surface note. No skin colour. Total 85 lines.
- New `f_body_anus` (16 lines) and `m_body_anus` (12 lines): rosette shape, radial folds, hair and the cheeks around it. No skin colour.
- `act_yoga_action` 3 -> 24 named poses; `act_dance_classes_action` 3 -> 20 moves; `act_martial_arts_action` 3 -> 20 stances, kicks and strikes.
- Clothes, equipment and setting lists for all three widened (leotards, leggings, fitted tops, training suits).

## Showcases
- Standard showcase: 40 prompts (yoga, dance, martial arts; the nipple ladder walked in order; women's and men's anal area).
- Body-feature showcase (not committed to git): 288 grids. Every feature grid is now completely nude, stated in each panel; only pose grids carry clothing. Nipple grids use the size ladder; anal-area grids use the new library files with matching buttocks shape; new yoga, dance and martial-arts pose grids use the v107 lists in suitable clothing.
