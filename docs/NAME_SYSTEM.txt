FAKE NAME SYSTEM (v94)

Everything that appears as text in a prompt (shop signs, labels, packaging, business cards, caps, t-shirts, book covers, comic covers, posters) comes from name files. The text shows up in quotes in the finished prompt, one line per item, with "No other words or letters appear." so the image model does not invent words. To customise, expand the prompt, then change the quoted text.

PARTS (change these to change every name built from them)
  name_stem_latin / nordic / german / tech / japanese   invented brand stems (Velova, Salby, Dorfeld, Zenon, Nutaro)
  name_surname, name_first, name_word                   invented surnames, first names, nature/object words
  name_trade_shop / food / corp, name_trade_<business>  Hardware, Bakery, Diner, Industries, Liquors...
  name_suffix_corp / shop                               Inc., Ltd., GmbH, & Sons / Store, Market, Emporium
  name_type_<group>, name_weight_<group>, name_variant_<group>   soft, sweet, savoury, spirit, household, other
  name_street, name_street_type, name_hours, name_tagline, name_year, name_phone, name_price, name_batch

EXISTING FILES REWIRED
  text_brand, text_shop_name, text_pub_name, text_ship_name, text_card_name, text_map_name now draw from this system; text_slogan keeps its old lines and adds new ones. So the roughly 170 older sign, advert and label prompts get defined, invented names automatically.

NOTES
  Websites and emails end in .example and phone numbers use 555 so they cannot be real. No real brands: stems were generated, not copied.

v109 additions: name_team (invented town-based team names such as "<town> Falcons", "<town> United", "FC <town>"), name_team_mascot (team mascot words), name_jersey_number (0 to 99). Used on jerseys, sportswear, trading cards, stickers and race bibs, always quoted.
