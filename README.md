# guyanonymous_wildcards
A slightly extensive wildcard system for generating text prompts for txt2img generation.  Focus is on natural language models e.g., Krea 2, Moss Image.

## Layout
- `wildcards/` the library (one `.txt` per wildcard, `__name__` syntax) and `wildcards/_tools/` the Python build tools (see `docs/HOW_TO_RUN.txt`).
- `docs/` indexes, notes and the changelog.
- Releases are tagged `vNN` (v74 is the first tagged version in git). Release zips and the All Options Once export are built from this tree and are not stored here.
- Local working folder: `D:\!!!!!!!Dave's Apps - Wildcards\Guyanonymous' Wildcards`.
